# AI Web Projects

A collection of AI-assisted web projects, educational tools, landing pages and interactive experiences.

These projects combine product thinking, AI-assisted development, educational design and practical user experience.

## Featured Projects

### 1. Counting Like Grown-Ups | סופרים כמו גדולים

An interactive early-childhood math app designed for kindergarten children.  
The app helps children practice number recognition, counting, matching, drawing numbers and completing playful math missions.

**Audience:** Kindergarten children  
**Domain:** EdTech, early math, interactive learning  
**Live Demo:** https://kingsolomon-gan-math-app.netlify.app/

---

### 2. Holiday Color by Numbers | צובעים את החג

An interactive color-by-numbers activity for kindergarten children.  
Children choose colors and paint the matching areas, combining visual attention, number recognition and holiday-themed learning.

**Audience:** Kindergarten children  
**Domain:** EdTech, visual learning, early numeracy  
**Live Demo:** https://kingsolomon-color-by-numbers.netlify.app/
